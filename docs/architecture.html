Factory Inventory Management System

A full-stack demo: Vue 3 dashboard, FastAPI service, and in-memory data loaded from JSON files. There is no database.

System architecture

Tech stack

Frontend

Vue 3 + Vite 8

  • Composition API, vue-router 4
  • axios for HTTP
  • Custom SVG charts, CSS Grid layouts
  • English and Japanese locales
Backend

FastAPI + Pydantic

  • Python 3.11+, served by Uvicorn
  • Typed models validate every response
  • Managed with uv
  • Interactive docs at /docs
Data and tooling

JSON files, pytest

  • Seven JSON files in server/data/
  • Held in memory, reset on restart
  • Backend tests: pytest + FastAPI TestClient
  • Claude Code agents, skills and MCP config in .claude/

Data flow

Request path

  1. The user changes a filter in FilterBar: period, warehouse, category or order status.
  2. useFilters holds that state as shared singleton refs. getCurrentFilters() maps the period to a month value.
  3. A view calls api.js, which adds each non-all filter as a query parameter.
  4. FastAPI filters the in-memory lists with apply_filters() and filter_by_month().
  5. Pydantic validates the result and returns JSON.
  6. The view stores raw data in refs, and computed properties derive totals and chart series.

Startup and state

  • mock_data.py reads every JSON file once when the server starts.
  • Nothing is written back, so changes are lost on restart.
  • Month filters accept 2025-01 or a quarter such as Q1-2025, matched against order_date.
  • Inventory records carry no date, so the month filter does not apply to them.
  • Reports (/api/reports/*) are aggregated on the fly from orders.

Observations

  • client/src/api.js defines /tasks and /purchase-orders calls, but server/main.py has no such routes. The Tasks modal and purchase order creation have no backend yet, and the CreatePurchaseOrderRequest model is defined but unused.
  • The base URL http://localhost:8001/api is hard-coded in the client.
  • CORS allows every origin and there is no authentication, which suits local demos only.
  • Quarter logic is duplicated: QUARTER_MAP and a hand-written chain in /api/reports/quarterly.
  • Dashboard.vue (about 1,270 lines) and Spending.vue (about 850) are the largest files and candidates for extraction.
